## 运行

在 `v0/` 目录：

```powershell
python -m http.server 8765
```

浏览器打开：

```text
http://127.0.0.1:8765/
```

回归：

```powershell
python smoke.py
python real_smoke.py
python live_check.py
python order_samples_smoke.py
python test_users_smoke.py
python mcp_smoke.py
```

`real_smoke.py` 覆盖：账单体检、三包目录、双时钟、价保资格、真实路径、受理/到账分开、回执导出、320–1440 响应式。
`order_samples_smoke.py` 用 8 张真实淘宝/天猫/京东/饿了么订单截图，校验实付金额与平台识别。
`test_users_smoke.py` 用 `图片/` 里 38 张真实订单做的 5 个**合成测试用户**，覆盖今天页、一句话立案、结果页、陪办页、家庭筛选、回执翻面、周/月/年报告、长辈模式与备份导入；数据说明见 `test_users/README.md`。
`mcp_smoke.py` 校验六个 MCP 工具的初始化、工具列表、资金查询/计划/回执，以及 `resolved` 必须有用户确认。

`real_samples/` 只存本地，包含姓名/电话/地址，**不要提交、不要部署**；应用本身不会把这些图上传。

手机同一局域网访问：把 `127.0.0.1` 换成电脑的局域网 IP。

不需要构建、不需要后端。

或用 Docker：

```powershell
docker build -t piaogen-v0 .
docker run --rm -p 8765:80 piaogen-v0
```

## 已知边界

- 规则已换成真实条款：三包第八至十二条、消保法第二十三至二十五条、民法典第五百八十六至五百八十八条；每张结果卡可点“查看原文”。价保属平台承诺，仍以订单页为准。
- 定金罚则函数 `PG.depositCalc` 已实现（20% 上限、超出部分、双倍返还），并接在装修定金票据的案卷/结果页。
- Tesseract 中文识别会有错字/漏字；低置信会标“OCR 需复核”，金额/日期必须用户确认。
- 弱网下快速模型可能下载超时；已改成明确提示“识别没完成 → 手动填三项”，不会让用户对着空白票发愣。
- 依赖/语言包已本地化，图片只在浏览器内处理，不上传。
- OFD 目前是基础 XML 文字提取；复杂 OFD（签章/嵌套对象）V1 接 ofdkit/服务端解析。
- 没有云端同步/家庭共享；家庭视角是本机“帮谁办”标记，不是多账号权限。当前用 JSON 导出/导入备份。
- 资金售后覆盖支付/退款、银行卡争议、续费、预付卡、分期息费和保险犹豫期；不提供贷款/保险推荐、投资建议、征信修复，也不索取完整卡号、CVV、验证码或密码。
- 没有自动投诉/自动退款/自动签字；高风险动作必须用户自己点。
- 没有接入支付宝支付后 1403/订阅消息；V1 做小程序时接。
