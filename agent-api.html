票根 · MCP 0.5.0 · 规则库 2026.11.21

可被调用

核对日期：2026-11-26　·　7 个工具　·　3 种接入形态　·　当场计算，不是返回固定示例

票根把「权利窗口、证据缺口、官方路径、材料与回执」做成可调用的接口。传日期和商品名，它当场算出还剩几天；不传参数才返回示例。同一个计算核心跑在三个地方：本地 stdio MCP、公网只读 MCP、以及给不认识 MCP 的调用方准备的 REST 接口。

MCP标准 JSON-RPC 2.0，initialize / tools/list / tools/call。适合支持 MCP 的客户端。
REST一个 POST 带 JSON 就出结果。适合脚本、低代码平台、只会发 HTTP 的调用方。
Skill 包整包 zip，含说明、引擎与契约。适合按技能加载的智能体平台。

1. 工具清单

工具做什么写操作
rights.lookup按购买日期当场算：无理由退货、三包退货/换货、价保、保修各剩几天，还缺什么证据。传 date + product 即可否
rights.plan基于同一次计算给下一步：做什么、带什么、去哪儿、别做什么否
rights.record回填办理结果；refunded / repaired / promise 必须 confirmed=true是，需确认
finance.lookup查六类资金售后：退款、拒付、续费、预付卡、分期、保险否
finance.plan给资金案卷生成证据门、官方路径与话术否
finance.record记录资金进度；只有 confirmed=true 才写已解决金额是，需确认
policy.parse从保单/合同只提取机构、金额、期限、签单日期；不返回证件号与原文否

公网端点只读，*.record 一律返回 public_read_only；写操作只在本地 stdio 与本地 HTTP 桥可用。

2. 三种接入

2.1 公网 MCP（已上线，推荐）

POST https://xiongxiongkaifa-d4flmaia4021b1d1-1506832756.ap-shanghai.app.tcloudbase.com/piaogen-mcp
Content-Type: application/json

{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18"}}
{"jsonrpc":"2.0","id":2,"method":"tools/list"}
{"jsonrpc":"2.0","id":3,"method":"tools/call","params":{
  "name":"rights.lookup",
  "arguments":{"product":"空调","amount":3299,"date":"2026-11-20",
               "receivedDate":"2026-11-20","today":"2026-11-26"}}}

上面第三个请求真的会算出「无理由退货剩 1 天」——因为 today 是 11-26、签收日是 11-20。不传 today 就按服务器当天算。

点一下，直接请求公网端点；不需要 Key。

2.2 公网 REST（不会说 MCP 也行）

# 算权利窗口
POST /piaogen-mcp/rights
{"product":"空调","date":"2026-11-20","today":"2026-11-26"}

# 要下一步与材料
POST /piaogen-mcp/plan
{"product":"空调","date":"2026-11-20","today":"2026-11-26"}

# 机器可读清单
GET  /piaogen-mcp/manifest.json
GET  /piaogen-mcp/openapi.json

REST 和 MCP 走的是同一个计算函数，返回内容一致。契约是 OpenAPI 3.1，可以直接导入 Postman / Apifox / 低代码平台。mcp/openapi.json

2.3 本地（数据不出本机）

# stdio（给支持 MCP 的客户端）
node mcp/server.js

# 本地 JSON-RPC over HTTP（只绑 127.0.0.1）
node mcp/http-server.js
# POST http://127.0.0.1:8787/mcp

4. 算的是什么

权利起算日依据没有依据时
线上 7 天无理由签收日消保法第 25 条缺签收日 → 标「待确认」，不猜
三包退货 7 天发票日三包规定（18 类目录）不在目录 → 明说「无法定三包」
三包换货 15 天发票日三包规定同上
三包修理发票日三包规定同上
整机 / 主要部件保修发票日三包规定 + 品牌承诺按品牌承诺，不套法定年限
价保订单页标识平台承诺（不是法定权利）没有标识就不倒计时

5. 安全边界

  • 默认只读；写操作必须显式 confirmed=true，并只写本机 records.local.json。
  • 不暴露 shell、文件系统、浏览器、支付或任意 HTTP。
  • 不代登录、不代提交、不代收款、不托管资金。
  • 不返回证件号、手机号、卡号、CVV、验证码；保单/合同只保留机构、金额、期限。
  • 公网端点无状态：不存输入、不落库、不发外部请求；每 IP 每分钟 60 次，请求体上限 64KB，CORS 只放行票根自己的页面。
  • 只接受票根认可的几个源站；其他来源不带 CORS 头，浏览器侧读不到响应。

6. 机器可读清单

mcp/manifest.json 列出 7 个工具、传输方式、computes 与安全开关；公网端点同路径也返回一份 /manifest.json。源码与测试说明见 mcp/README.md。
