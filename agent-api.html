票根 · MCP 0.4.2

可被调用

核对日期：2026-11-25　·　7 个工具　·　stdio + 本地 HTTP 桥

票根不只是一个页面。它把“权利窗口、证据缺口、官方路径、材料与回执”做成 7 个 MCP 工具，别的 Agent 可以按标准协议调用。当前只在本机运行，公网没有托管 MCP 服务。

1. 工具清单

工具做什么写操作
rights.lookup查一笔购买的消费权利：还能做什么、最近哪天关闭、缺什么证据否
rights.plan给一宗案卷生成下一步、材料、话术、官方入口否
rights.record回填办理结果；refunded / repaired / promise 必须 confirmed=true是，需确认
finance.lookup查六类资金售后：退款、拒付、续费、预付卡、分期、保险否
finance.plan给资金案卷生成证据门、官方路径与话术否
finance.record记录资金进度；只有 confirmed=true 才写已解决金额是，需确认
policy.parse从保单/合同只提取机构、金额、期限、签单日期；不返回证件号与原文否

2. 本地启动

# stdio（给支持 MCP 的客户端）
node mcp/server.js

# 本地 JSON-RPC over HTTP（只绑 127.0.0.1）
node mcp/http-server.js
# POST http://127.0.0.1:8787/mcp

3. 调用示例

先列工具：

{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}

再查一笔权利：

{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{
  "name":"rights.lookup",
  "arguments":{"query":"空气炸锅","amount":299,"date":"2026-11-13"}
}}

4. 安全边界

  • 默认只读；写操作必须显式 confirmed=true，并只写本机 records.local.json。
  • 不暴露 shell、文件系统、浏览器、支付或任意 HTTP。
  • 不代登录、不代提交、不代收款、不托管资金。
  • 不返回证件号、手机号、卡号、CVV、验证码；保单/合同只保留机构、金额、期限。
  • HTTP 桥只绑 127.0.0.1，CORS 只放行 localhost；公网没有托管。
