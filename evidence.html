票根 · V9.4

核验与边界

核对日期：2026-11-23　·　这一页只写能当场复核的事实

评委不需要翻文档：这一页列出规则条数、测试基线、数据处理方式、AI 的位置，以及我们明确不做的事。数字来自当天实跑；与页面不一致时，以实际运行结果为准。

1. 这个作品现在是什么

  • 可安装的 Web 应用（PWA），纯静态、无后端、无账号；数据只存本机 localStorage。
  • 六栏：今天 / 案卷 / 资金 / 资产 / 导入 / 我的；消费权利与资金售后共用同一套案卷、证据、回执引擎。
  • 可被调用：本地 MCP server 六个工具，协议 initialize → tools/list → tools/call；另附本地 JSON-RPC over HTTP 桥（只绑 127.0.0.1）。
  • 未接入：支付宝小程序、支付后 1403、订阅消息、蚂蚁阿宝真实调用。这些只在路线里，不在产品里。

2. 规则与依据

  • 规则库 20 条，每条带条款号、施行日期与原文链接。
  • 自动续费以《互联网平台价格行为规则》为准：2026-04-10 起，每次扣款前应显著提醒时间、金额、取消途径，并允许随时取消。
  • 三包目录 18 类；目录外商品不显示法定 7/15 日；线上 7 天无理由从签收日算，三包 7/15 日从发票日算，两个时钟分开显示。
  • 价保是平台/商家承诺，不是法定权利；没有订单页价保标识就不显示倒计时。

4. 数据与 AI

  • 票据图片、PDF、OFD 在本机识别；不上传原图，不写入远端数据库。
  • AI 建议层默认关闭。打开后由用户自填 OpenAI 兼容端点、模型与 Key；发送前展示将发送的字段，金额与日期默认不发送。
  • AI 只产出建议文本，只进“事实与诉求”备注；不改金额、日期、状态、证据，不参与结论。
  • 关掉 AI，权利窗口、证据门、路径、回执全部照常工作。
  • 资金案卷只填卡尾号；不索取完整卡号、CVV、验证码、网银密码。

5. 明确不做

  • 不代登录、不代提交、不代收款、不托管资金。
  • 不承诺“保证退回 / 保证拒付成功”，不做法律、金融、医疗的确定性结论。
  • 不做贷款推荐、保险推荐、投资建议、征信修复。
  • 没有公开依据的固定天数不倒计时。
  • 争议金额、预计可追回、确认解决金额三口径分开；只有用户确认到账，才计入已解决金额。
  • 示例数据标“示例”；MCP 不暴露 shell、文件系统、浏览器、支付或任意 HTTP。

6. 已知局限

  • 纯 localStorage，没有云同步与多设备；家庭是“帮谁办”的标记，不是共享账号。
  • 中文票据 OCR 仍会错字；金额与日期必须用户核对；复杂 OFD 不支持。
  • 远程 MCP 未托管；官方 Streamable HTTP 未实现。
  • 支付宝小程序壳与支付后入口只有设计与原型，未接入。

7. 怎么复核

在项目 v0/ 目录运行：

python -m http.server 8765
python test_users_smoke.py
python smoke.py
python real_smoke.py
python order_samples_smoke.py
python mcp_smoke.py
python mcp_http_smoke.py
python doc_check.py

MCP 复核：node mcp/server.js（stdio）或 node mcp/http-server.js（本地 HTTP 桥），再按 mcp/README.md 调 tools/list。
