核验与边界

核对日期：2026-11-25　·　这一页只写能当场复核的事实

评委不需要翻文档：这一页列出规则条数、测试基线、数据处理方式、AI 的位置，以及我们明确不做的事。数字来自当天实跑；与页面不一致时，以实际运行结果为准。

1. 这个作品现在是什么

  • 可安装的 Web 应用（PWA），纯静态、无后端、无账号；数据只存本机 localStorage。
  • 五栏：今天 / 案卷 / 助手 / 资产 / 我的，助手居中；资产页分段切换「资产 / 资金售后 / 健康」，导入并入今天与资产。
  • 权利库：80 条可查条目（法定依据、三包目录、平台路径、解约指引、证据清单、价保），每条带出处、生效时间与官方链接。
  • 健康账本：健康支出、保障、复诊提醒与办事路径，只记本机；不做诊断、不推荐药品与保险。
  • 可被调用：本地 MCP server 七个工具（含 policy.parse），协议 initialize → tools/list → tools/call；另附本地 JSON-RPC over HTTP 桥（只绑 127.0.0.1）与公网只读端点（CloudBase，已上线，示例数据、限流、CORS 白名单）。
  • 内置规则 Agent（助手栏、顶栏 ✦ 与悬浮小票灵）：七类意图——查到期、资金售后、权利窗口、材料准备、本月支出、会员年费、快过期券；“帮我排今天”会同时查到期、资金截止、证据缺口与周期扣款，排成 3 件事并给动作；逐轮补齐金额与日期，不联网、不需要 Key，支持语音输入。
  • 助手不再只是一个对话框：底部「助手」是完整对话页；每个页面右下角有悬浮的「小票灵」，按当前页给建议；这张票、案卷、导入、资金与办结页都有「问小票灵」按钮，带着当前场景直接问；同一段对话在悬浮窗与完整页之间接续，不清空。
  • 智能模式：可选外接任意 OpenAI 兼容模型（含本机 Ollama）。模型只调用七个本地只读工具（到期清单、搜案卷、读案卷、资金规则、材料清单、查规则、算截止日），每轮输出 JSON；金额与日期必须来自工具结果或你的原话，未核对数字会标黄；失败自动回落本地规则。
  • 没有 Key 也能看智能模式怎么工作：助手内有“协议示例”，展示模型如何先查案卷、再算截止日、最后给结论；示例标明不是实时模型输出。
  • 支付后入口已实现 URL 参数契约：?from=afterpay&merchant=…&amount=…&order=…，同一交易号不重复建案；PWA 支持系统分享（share_target），分享文本会打开立案框。
  • 支付宝小程序壳是真实可编译源码（alipay-mini/，web-view 壳），但未发布、未审核、没有 AppID；不要把它当成已接入。
  • MCP 七工具另有机器可读清单 mcp/manifest.json 与公开说明页 agent-api.html；公网只读端点已上线：https://xiongxiongkaifa-d4flmaia4021b1d1-1506832756.ap-shanghai.app.tcloudbase.com/piaogen-mcp（GET /health 可当场验，写操作返回 public_read_only）。支付宝五个接入面见 alipay.html。
  • 订单截图 / 录屏可多选，逐张识别后一起分拣；读不出的单单独标出，不猜字段。
  • 支付宝账单 CSV：从“交易流水证明”导出的 CSV 可在本机导入，自动识别 UTF-8 / GBK，提取时间、对方、商品、收支与金额；同一商户连续扣款会提示疑似续费。文件不上传。
  • 支付宝接入面：alipay.html 列出支付后 URL、小程序 web-view、账单 CSV、MCP 四个面，逐项标明已实现与未接入。
  • 办事台（今天页与资产页可进）十件事：账单月报、还能退、续费决策、权益账本、储值卡、比价卡、找谁、诉求助手、保修日期卡、家庭体检单。账单支持支付宝/微信/银行 CSV 与 Excel（.xlsx 第一个工作表），跨渠道按同日同额同商户合并，并给出日均、退款笔数、分类占比与「可能白花的钱」（续费/券/卡三笔分开，不计入支出）；「还能退」把权利、券、积分、卡、续费、保修按截止日排成一张单，可筛选、导出 `.ics`；「比价卡」只记用户亲眼看到的价格，显示涨跌与历史低高，可一键建价保案卷；囤货按“数量 ÷ 每天用量”算可用天数与补货预算；30 类场景给出先找谁、步骤与材料；诉求只生成文字，带语气与约 200 字短版；保修按购买日与月数算到期；家庭体检单含 8 项防诈自检与「帮爸妈三步」，可打印或转发。全部在本机运行，不登录、不上传。
  • 收件箱：把扣款、退款、到期、快递、催缴、验证码短信贴进来，本机规则识别对方、金额、日期、订单号与意图，给出建案 / 记流水 / 记续费 / 加提醒 / 找谁 / 写诉求六个动作；快递类可开「签收异议 · 72 小时」行动卡（快递员 → 企业客服 → 12305），并转支付争议案卷；同一条通知不重复，不点链接、不回拨、不上传原文。
  • 真实用户测试台：内置 5 个任务（示例、账单、还能退、诉求、家庭单），自动判定完成、记录用时与提示次数，导出 JSON；只存编号，不收集姓名、手机号、地址，可随时清空。
  • 自定义到期提醒：自己加一条「宽带到期 / 车险续保 / 取快递」，进入「还能退」、家庭体检单与导出的日历；可编辑、可删除。
  • 续费周期：支持每周 / 每月 / 每季 / 每年，统一换算月均与一年合计；不是所有续费都按月。
  • 家庭年度总览：今年的账单支出、退款收入、已确认守住、续费可省、卡余额与到期券，一张单打印或转发；三种金额口径仍然分开。
  • 完整备份：导出的 JSON 现在含票据、账单、提醒、卡券与决策，可换设备恢复；备份文件请自己保管。
  • 预付卡案卷显示七日退款窗口（付款日起 7 个自然日，第 7 天日期）、可主张本金估算与「一经售出不退」等条款的无效提示；窗口外只提示迁店、擅自转店、无法服务等情形，不倒计时、不承诺退款。
  • 支付宝只读交易查询适配层：cloudfunctions/piaogen-alipay/ 用商户自己的凭据调 alipay.trade.query，RSA2 签名、响应验签、只回白名单字段、买家账号脱敏；未部署，需要凭据，缺凭据返回 not_configured。离线自检 10 项通过。
  • 保单 / 合同导入只提取机构、金额、期限三项，不保存证件原件、证件号与完整文字；结果由用户确认后才建立资金案卷。
  • 未接入：支付宝小程序发布、支付后 1403 真实回调、订阅消息、蚂蚁阿宝真实调用。已有可编译的 web-view 小程序壳源码（未发布）与 支付后 URL 参数契约（原型）；不写成“已接入”。
  • 响应阿宝许愿池：372 票「帮我揪出悄悄扣钱的自动续费」；另有「帮我写投诉」同类愿望。票数取自公开许愿池，只作需求证据，不代表评审加分。
  • 永久免费：无会员、无充值、无扣费、无广告、无隐形消费；不代提交、不代收款。

2. 规则与依据

  • 规则库 22 条，每条带条款号、施行日期与原文链接。
  • 自动续费以《互联网平台价格行为规则》为准：2026-04-10 起，每次扣款前应显著提醒时间、金额、取消途径，并允许随时取消。
  • 三包目录 18 类；目录外商品不显示法定 7/15 日；线上 7 天无理由从签收日算，三包 7/15 日从发票日算，两个时钟分开显示。
  • 价保是平台/商家承诺，不是法定权利；没有订单页价保标识就不显示倒计时。
  • 依据可打开：每个权利窗口与资金结论都能展开“条文要点 / 白话 / 能维护你什么 / 检索式”，并给出官方页面；只摘与本案有关的要点，不冒充全文。
  • 自动填出的截止日（如“签收日 + 合同犹豫期”）会标待核对，用户改过就自动去掉。

2.5 什么时候会否决自己

  • 证据不齐时，资金合议的审计单元直接否决提交，并列出还缺哪几项，不假装已办完。
  • 材料里没有订单页价保标识，就不显示价保倒计时，只写“以订单页为准”。
  • 银行卡 / 信用卡争议没有公开统一时限，就不倒计时；只按银行或卡组织给你的截止日。
  • 保单 / 合同 OCR 只提取机构、金额、期限；证件号与原文不保存，也不回显。
  • 批量导入里读不出的单标“识别失败 · 手动填”，不猜金额与日期。

4. 数据与 AI

  • 票据图片、PDF、OFD 在本机识别；不上传原图，不写入远端数据库。
  • AI 建议层默认关闭。打开后由用户自填 OpenAI 兼容端点、模型与 Key；发送前展示将发送的字段，金额与日期默认不发送。
  • AI 只产出建议文本，只进“事实与诉求”备注；不改金额、日期、状态、证据，不参与结论。
  • 内置规则 Agent 不调用外部模型：意图、槽位、金额与日期都由本地规则库解析，界面会显示“理解 / 工具 / 下一步”，便于核对。
  • 智能模式是可选开关：Key 只存本机；只发送当前这句话、本地概况与工具结果；不发图片、卡号、订单号、手机号、地址、验证码。
  • 本机真实模型实测（2026-11-25）：Ollama `gemma3:12b` 约 30.1 秒，先调 `list_urgent`，回答引用 5 条本地到期项；不是 mock。评委仍需自备 Ollama 或 Key。
  • 关掉 AI、断开网络，权利窗口、证据门、路径、回执与内置 Agent 全部照常工作。
  • 资金案卷只填卡尾号；不索取完整卡号、CVV、验证码、网银密码。

5. 明确不做

  • 不代登录、不代提交、不代收款、不托管资金。
  • 不承诺“保证退回 / 保证拒付成功”，不做法律、金融、医疗的确定性结论。
  • 不做贷款推荐、保险推荐、投资建议、征信修复。
  • 没有公开依据的固定天数不倒计时。
  • 争议金额、预计可追回、确认解决金额三口径分开；只有用户确认到账，才计入已解决金额。
  • 示例数据标“示例”；MCP 不暴露 shell、文件系统、浏览器、支付或任意 HTTP。

6. 已知局限

  • 纯 localStorage，没有云同步与多设备；家庭是“帮谁办”的标记，不是共享账号。
  • 中文票据 OCR 仍会错字；金额与日期必须用户核对；复杂 OFD 不支持。
  • 公网 MCP 只托管示例数据，不托管用户票据；官方 Streamable HTTP 未实现。
  • 支付宝只读交易查询适配层未部署，也没有用真实商户凭据跑通；订阅消息模板 ID 未申请。
  • 支付宝小程序壳（miniapp.html）与支付后入口（afterpay.html）只有设计与原型，未接入。

7. 生态闭环：一条付款之后的路

  1. 收得进来：拍票 / 截图 / PDF / OFD、支付宝与微信账单 CSV / Excel、粘贴一条扣款或催缴短信。文件与文字都只在本机解析。
  2. 算得清：权利窗口、三包与价保、六类资金售后、账单分类、续费按周/月/季/年换算成月均与一年合计。
  3. 办得成：30 类「找谁」给出先找谁、步骤与材料；诉求助手生成事实、诉求与材料清单；一键进入案卷，证据门不齐会否决提交。
  4. 提醒得到：「还能退」把权利、券、积分、卡、续费、保修与自定义提醒排成一张单，可导出 .ics；家庭体检单给爸妈看。
  5. 留得下：回执、办理时间线与三种金额口径（争议 / 预计可追回 / 确认解决）分开记；只有你确认到账才计入已解决。
  6. 传得出去：家庭单可打印 / 转发；完整备份含票据与办事台，可换设备恢复（文件自己保管）。
  7. 调得动：本地 MCP 七个只读工具、调用示例与公网只读端点（…/piaogen-mcp/health）。

这七步对应产品里的固定入口：今天 → 办事台（今天页 / 资产页进入）→ 案卷 → 报告。闭环的意思不是功能多，而是每一步都能回到下一步，不用重新找入口。
